# stratolabhq.github.io

Link-in-bio page for the Instagram account [@stratolabhq](https://instagram.com/stratolabhq),
published with [GitHub Pages](https://pages.github.com/) at <https://stratolabhq.github.io>.

Built on [LittleLink](https://littlelink.io) by Seth Cottle
([sethcottle/littlelink](https://github.com/sethcottle/littlelink)). Original MIT license
retained in [`LICENSE.md`](LICENSE.md).

## Structure

| Path | Purpose |
| --- | --- |
| `index.html` | The link page itself |
| `privacy.html` | Privacy overview (linked from the footer) |
| `css/` | `reset.css`, `style.css`, `brands.css` from LittleLink |
| `fonts/` | Open Sans woff2 files |
| `images/` | `avatar.png` / `avatar@2x.png` plus `images/icons/` brand SVGs |

## Editing

It is plain static HTML/CSS. Edit `index.html`, commit, and push to `main` &mdash; GitHub Pages
redeploys automatically. Button classes and icons come from LittleLink; see the
[LittleLink wiki](https://github.com/sethcottle/littlelink/wiki) for adding buttons.
